## Project Scope:
- [ ] Creation of Login and Registration of User
- [ ] Admin: Manage Guest House Details
- [ ] Admin: Manage Rooms (add room type, price, capacity)
- [ ] Guest: View Guest House and Rooms, Check Availability
- [ ] Booking a Room and Checkout with Stripe
- [ ] GST Tax Calculation on Payment
- [ ] Receipt Generation after Payment
- [ ] Admin: View Booking Logs


## Out of Scope:
- [ ] Multiple guest houses / properties
- [ ] Email Notification to Users when registration
- [ ] Stripe seller onboarding (only one admin manages payments directly)


## Objectives:
- [ ] Create a usable web application for GCIT Guest House bookings.
- [ ] Display accurate guest house and room information for seamless booking.
- [ ] Create easy to navigate navigation and booking/payment confirmation messages.
- [ ] Give the admin an easy way to manage rooms, monitor booking activity, and track GST collected.


## Technology Stack:


- JavaScript
- Node js
- Express Js
- PostgreSQL
- JWT
- React
- React Bootstrap
- Redux
- Stripe
